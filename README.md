##  Core Capabilities

###  **Intelligent Document Capture**
Leverage your device's camera to instantly capture any document — receipts, business cards, contracts, handwritten notes, or ID cards. The intuitive viewfinder helps you frame perfectly every time.

###  **Professional-Grade Enhancement**
Transform dark, shadowy, or faded scans into crisp, readable documents. Fine-tune with precision controls:
- **Brightness** adjustment for poorly lit captures
- **Contrast** control to make text pop
- Real-time preview — see changes before you save

###  **Effortless Document Management**
Everything in one place. Your scanned documents live in a sleek, organized library where you can:
- Browse through all your scans in a clean grid or list view
- Preview documents full-screen with pinch-to-zoom
- Delete unwanted scans instantly
- Access your entire document history at a glance

###  **Truly Cross-Platform**
Built with Flutter for a native experience everywhere:
- **Android** — Full camera integration
- **iOS** — Smooth performance on iPhones & iPads  
- **Web** — Basic functionality for browser-based access
